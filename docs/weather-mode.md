# 《源河 · Lumera》· 混沌天气（DLC）规则

> **这是叠加在经典规则之上的可选玩法（DLC）。** 经典规则见 [game-rules.md](game-rules.md)——那是默认、完整的对局；本文只描述「混沌天气」开启后**新增或改变**的部分，未提及处一律沿用经典规则。世界观上：源大多时候只是静静地转，但偶尔会亲自搅动这条河——那一搅，就是一场天气。

---

## 一、这是什么

混沌天气是一个**开关**。开启后，每当开启一道新梯，都有一定概率「降下」一种天气，为这一梯（或全场）加一层噪声：可能全场发牌、可能打乱手牌、可能凭空升压、可能整梯刮着转向/禁止、也可能奖励敢在高压下出手的勇者。

它**不改动经典的核心循环**（盖牌宣称 → 质疑摊牌 → 轮盘受罚 → 打 0 / 跑成 / 计分），只在「开新梯」的那一瞬间额外掷一次「天气骰」。关掉开关，就是纯粹的经典模式。

---

## 二、如何开启

- **单机**：开始页勾选「混沌天气」。
- **联机**：房主在房间大厅实时开关，作为房间设置同步给全员；非房主只读。
- **配置**：`GameConfig.weather`（总开关，默认 `false`）、`GameConfig.weatherChance`（每开新梯的触发概率，默认 `0.28`）。

---

## 三、何时降天气（触发规则）

- **时机**：只在**开启一道新梯**（首家起手）的那一刻判定一次；梯子中途的平稳接牌不会触发。
- **概率**：每次开新梯，以 `weatherChance`（默认 28%）掷一次决定本梯是否降天气。
- **开局豁免**：**开局第一梯永不降天气**，让对局平稳起步。
- **隔梯冷却**：一旦降下天气，**至少隔 1 梯**才可能再降（冷却 = 1 梯），避免天气连下糊脸。
- 因此**实际观测到的触发率低于 28%**（被开局豁免与隔梯冷却拉低）——这是有意的节奏控制：天气是点缀，不是主旋律。
- **人数限制**：**2 人局不会降「禁制 / 乱向」**（转向、禁止在两人桌等同空过），它们只在 3–4 人局出现。
- **一梯一天气**：本梯的天气在开梯时定下、整梯作为**公开信息**对全场可见；换梯即清，下一梯重新判定。

---

## 四、六种天气

分两类：**一次性**（开梯立即结算）与 **持续整梯**（本梯每次出牌后再判定）。

### 一次性（开梯立即生效）

| 天气 | 效果 | 影响 |
|------|------|------|
| **丰沛** | 全场在场玩家各**摸 2 张**手牌 | 手牌变厚：选择更多，但也更难清空跑成 |
| **乱流** | 全场各抽 **2 张**（不足则有几张抽几张）投入公共池，**混洗后按各人投入数原样发回** | 手牌数不变、牌张守恒，但**内容被打乱**——之前的记牌与盘算被洗掉，重新读局 |
| **源涌** | 全场**受罚累进 +1~2**（封顶 6） | 全场同时升压：下一次受罚就更接近中枪 |

### 持续整梯（本梯每次出牌后判定）

| 天气 | 效果 |
|------|------|
| **禁制** | 本梯**每次出牌后，40% 概率**附带一次「禁止」（跳过下家） |
| **乱向** | 本梯**每次出牌后，60% 概率**附带一次「转向」（反转出牌方向） |
| **恩泽** | 本梯里，**打出 0**（顶格终结本梯）或**清空手牌「跑成」**的玩家，额外 **+2~4 分**（计入计分卡）。被质疑翻真仍跑成也算 |

> **恩泽是「指向性奖励」**：它不平均撒钱，而是专门加码那些在高压梯上敢打 0 止损、或敢赌最后一张跑成的勇者操作——把天气变成一根鼓励主动博弈的杠杆。若本梯无人打 0、也无人跑成（以受罚收场），恩泽就是一场空梯。

---

## 五、与经典规则的衔接

- 天气只在「开新梯」这一步加料；料下完之后，这一梯照**经典规则**照常走完（盖牌宣称、质疑摊牌、轮盘受罚、打 0、跑成、计分）。
- **持续天气（禁制/乱向）触发的，是经典里本就存在的「禁止/转向」效果**，只不过这次由天气随机附加，而非玩家主动明甩功能牌；玩家本回合的数字牌动作不受影响。
- **恩泽的额外分计入计分卡**（与「打 0 领计分卡」同一计分维度），最终按经典计分公式汇总。
- 受罚轮盘、死亡判定、终局条件等其余机制**全部不变**。

---

## 六、确定性与公平

- 天气的**全部随机**——是否降、降哪种、源涌/恩泽的点数、乱流的混洗顺序、禁制/乱向每次是否触发——一律走引擎的**种子化 RNG**，绝不调用系统随机。因此**同一种子完全可复现**（便于回放、调试、联机时由服务器掌控）。
- 天气**对全场对称施加**：丰沛/乱流/源涌全场同受；持续天气对本梯每次出牌一视同仁，不偏袒任何座位。

---

## 七、验证

`npm run sim:weather`（[../web/src/engine/simWeather.ts](../web/src/engine/simWeather.ts)）开启天气跑 **1000 场**，逐局断言与经典模拟同样的不变量——引擎不崩、牌张守恒、必然终局、无信息泄露、命数/累进不越界——并额外校验：

- **确定性复现**：24 组「同种子跑两遍」结果逐字节一致（验证天气随机确实全走 `s.rng`）；
- **频率与分布**：天气触发率、六类天气占比；
- **对节奏的影响**：天气局 vs 经典局（同种子）的对局长度、总掉命数对比；
- **公平性自检**：各座位胜率应近均匀。

## 附：可调参数一览

| 参数 / 常量 | 默认 | 含义 |
|------|------|------|
| `weather` | `false` | 总开关 |
| `weatherChance` | `0.28` | 每开新梯触发天气的概率 |
| `WEATHER_COOLDOWN` | `1` | 触发后冷却梯数（至少隔 1 梯） |
| 丰沛 | `+2 张` | 全场各摸牌数 |
| 乱流 | `2 张` | 每人投入混洗池的张数 |
| 源涌 | `+1~2`（封顶 6） | 全场受罚累进增量 |
| 禁制 | `40%` | 本梯出牌后触发「禁止」概率 |
| 乱向 | `60%` | 本梯出牌后触发「转向」概率 |
| 恩泽 | `+2~4 分` | 打 0 / 跑成勇者的额外得分 |
