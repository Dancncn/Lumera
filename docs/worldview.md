# 《源河》· 世界观与背景故事定稿

---

## 一、源

最初只有一条流转的光。它没有形状，同时含着所有颜色，既不昼也不夜，既不争也不欲——它只是在。这就是**源（Lumera）**，是这个世界里那张炫彩如银河的牌，也是这个世界的全部由来。

源是一种道：无形，而四方由它而生；无心，而万物绕它周行。

当源第一次静下来，它裂开了。不是被谁劈开，是水满则溢——它**同时**裂成四道不能相融的光，四者地位全然对等，谁也不比谁先、不比谁高。

## 二、四力

四道光，是构成世界的四样东西。它们不是神，没有脸、没有血缘、没有眷属，也没有意志。它们是纯粹的材料，各自流动，亘古绕着彼此旋转：

- **阳 · Aurel** — 白与金。被看见的，白昼的，显形的。
- **月 · Selvar** — 黑与银。倒映的，夜的，藏起来的。
- **地 · Verda** — 青与褐。成形的，扎根的，有重量的。
- **海 · Thalos** — 深蓝。流动的，深的，退而又来的。

四力彼此不相恨。这个世界里没有战争——只有水遇水。两股水流相遇的地方，会互相挤、回卷、把对方逼退；那不是恶意，只是流动的东西相遇时本来就会发生的事。所有的对抗，都长在「河流交汇」这一个比喻里，不在四力的心里——它们没有心。

## 三、意志

源是无欲的。但它分出的每一缕意志，一旦离了整体，就染上了**欲**——渴望创造，渴望壮大，渴望把四力拢成一个属于自己的、能站得住的创造。

**你，就是源的一缕意志。** 你不效忠任何一股力（所以你四种颜色都引得动）；你只想赶在被收回之前，第一个汇成。

这是《源河》整个故事的核心：它演的不是那条静止无欲的道，而是**离了道的那一念欲**，在拼命想要流回去之前，先把自己活成点什么。

## 四、河 —— 一局是怎么回事

一局《源河》，就是诸多意志引着各自掌管的水，涌向同一个交汇处、争着先汇成。

- **手牌**：还没流出去的水，淤在你这儿，等着汇进大旋转。
- **出牌**：把一股水放进交汇处——它流动、加入旋转，成为创造的一部分。
- **反噬（摸牌）**：你想推进去的力没被接住，就回卷过来反噬到你身上，你的水反而越积越涨。反噬不是天降的霉运，是**有因果的**——是你去推了一股接不住的力，那股推不出去的水于是回卷成你的，淤在手里、越积越涨，成为你应得的滞重。
- **汇成（获胜）**：你的水全数流出、汇回大流。你成了，创造站住了——你回去了。
- **回流（落败）**：你没赶上这次汇合，只能归源，退回那条未分的光里。

而回流，对一缕**正在渴望**的意志来说，是不甘的。它本可以汇成，却差了一步；它不想回去，却被收了回去。所以它会带着这口不甘，在下一轮轮子转过来时更饥渴地重新涌出——「这把没成，下把我要先汇成。」一局接一局打下去的理由，就藏在这点不甘里：一缕想壮大的意志，永远会回来赶下一次汇合。

## 五、命运之轮

一局终了，所有回流的意志重新立在源面前。源会下一念之判：**下一轮，谁先涌出。**

这道判决，就是**命运之轮**——一面只在两局交接时转动的转盘。它不碰任何一张牌（规则一个字不改），只决定先手归谁；而先手，就是源短暂的恩准。轮子转起来的样子，就是这世界的样子：源在转，命运在转，周行不殆的大循环在转——全是同一个圆。

> （注：命运之轮属世界观设定；当前版本单局结算即止，跨局先手转盘尚未实现，留待轮子真正转起来的那一天。）

## 六、底色

- **皮（玩家看见的）是西方的**：幽灵般的古典立柱、金色的细线、衬线与斜体、沿圆周散落的星点；还有那些查无此物、却像是某个古老文明留下的名字——Aurel、Selvar、Lumera。
- **骨（玩家感受到的）是东方的**：无形而生万物的源（道）、无善恶的四力、周行复归的循环。

玩家读到的是异国的质地，体会到的却是一套循环不争的东方骨。这点落差，就是「熟悉又陌生」的来处。

## 七、命名法与桌面用语（给开发用）

名字分两层，**读的**和**说的**不必是同一个：

- **读（牌面 / 世界 / 美术）**：用造名 —— 阳 Aurel、月 Selvar、地 Verda、海 Thalos、源 Lumera。识别它们、对上号的那个瞬间，就是乐趣。
- **说（桌面快速喊牌）**：喊颜色最顺 —— 金 / 银 / 绿 / 蓝 / 源；或单字 —— 阳 / 月 / 地 / 海。一个音节，不依赖任何造词。
- **功能牌**：每巡都要喊，名字必须短而脆，或干脆只用符号说话（skip / reverse / 源）。
- 数字与功能永远以清晰为先，绝不为了好看牺牲一眼可读。

> 以上造名（Aurel / Selvar / Verda / Thalos / Lumera；玩家可称 Lumir，「从 Lumera 裂出的一缕」）都是种子，随你替换；世界是你的。

## 附：背景故事（给规则书内页）

> 起初，只有一条光在流。
>
> 它没有边、没有名，把所有颜色都含在身体里，谁也分不出昼与夜。它不急着去哪儿，因为它就是一切要去的地方。
>
> 后来它停了一瞬。就那一瞬，它裂了——金的、银的、青的、蓝的，四道再不能相融的水，从此绕着彼此打转，世界就在这旋转里一点点成了形。
>
> 而每当那条光分出一缕意志，这缕意志一离开它，就忘了自己原本无欲。它开始想要：想把四道水拢到手里，想汇成一个只属于自己的创造，想在被收回去之前，先成为点什么。
>
> 它们一缕缕地涌出来，挤在同一个交汇处，争着第一个汇成。成了的，流回大流，圆满地归于光；没成的，被收回那片未分里——带着一口不甘，等轮子再转，再涌一次。
>
> 你，就是其中一缕。
>
> 轮子已经在转了。
